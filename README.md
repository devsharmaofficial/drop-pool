# DropPool 🥗

> **Good food. Better prices. Less waste.**  
> A demand-first surplus food matching platform connecting price-conscious locals with restaurant surplus meals before they go to waste.

## ✨ Features
- **Demand-First Matching**: Customers share what they're looking for, budget, distance, and pickup window; requests group into local demand pools.
- **Merchant Surplus Offers**: Restaurants and cafes view real-time privacy-safe local demand and publish eligible surplus inventory.
- **Smart Matching Engine**: Ranks and pairs offers with pooled customer demand based on dietary fit, quantity, distance, price, and pickup timing.
- **Interactive Prototype**: Fast, zero-friction demo experience built with React, Vite, Tailwind CSS, and Framer Motion.

## 🛠 Tech Stack
- **Framework**: [React 19](https://react.dev/) + [Vite](https://vite.dev/)
- **Language**: TypeScript
- **Animations & Icons**: [Motion](https://motion.dev/) & [Lucide React](https://lucide.dev/)
- **Deployment**: [Vercel](https://vercel.com/)

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm, pnpm, or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/devsharmaofficial/drop-pool.git
cd drop-pool

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
